# Game gallery and concept-board patterns

Use this file for multi-panel pre-production boards whose purpose is to explore or communicate a coherent game world across characters, environments, maps, props, symbols, and presentation views. Use `game-asset-patterns.md` for individual production assets and `game-hud-patterns.md` for complete gameplay screens.

These boards are review artifacts, not proof that every depicted item is a separately usable asset. Split accepted concepts into individual asset contracts before production.

## Shared board rules

- State canvas, grid or panel geometry, and every panel's role before art direction.
- Give each panel one subject and enough negative space to remain readable.
- Define shared projection, character identity, costume motifs, architecture, symbols, materials, palette, lighting, and detail density.
- Distinguish intentional variants from consistency errors.
- Supply exact short labels or omit them; do not request invented explanatory microtext.
- Reject a visually attractive board when panels merge, repeat, contradict the world rules, or look like unrelated images.

## Nine-panel worldbuilding set

```text
Create one square 3×3 pre-production worldbuilding board for an original dark-fantasy game world called "Saltwind Reach". Assign exactly one role to each equal panel in row-major order: 1 storm-battered coastal fortress at dawn; 2 foggy market street; 3 knight relic close-up; 4 map fragment; 5 monster silhouette study; 6 candlelit tavern interior; 7 alchemist kit flat lay; 8 moonlit harbor; 9 faction banner concept.
CONSISTENCY: painterly realism; muted teal / rust / bone palette; salt-worn materials; repeated faction geometry; compatible costume, architecture, symbols, scale cues, weather, and light behavior across all panels.
LAYOUT: clean gutters, no merged panels, one focal subject per panel, and only short exact labels when supplied. The board must read as one art-directed game world rather than nine unrelated illustrations, a mood collage, or a gameplay screenshot.
```

Evaluate both panel quality and cross-panel world coherence. A strong individual image does not compensate for conflicting motifs or materials elsewhere on the board.

## Hybrid character-and-city design board

```text
Create one landscape 16:9 game design board titled "NEON ORCHID DISTRICT" using five clearly separated asymmetric panels: 1 one large rain-soaked elevated-market environment; 2 and 3 close portraits of two distinct original adult couriers; 4 one small isometric alley-and-drone-route map; 5 one artifact panel containing transit passes, cybernetic gloves, and vending-machine stickers.
Use one coherent retro-future visual system: neon magenta / cyan / acid-green accents, wet asphalt, chrome and translucent materials, repeated orchid geometry, compatible signage, courier equipment, district architecture, and controlled night lighting. Preserve readable editorial margins and exact supplied labels. Do not merge panels, repeat the same portrait, invent brand logos, overload the map with prose, or let the board become a generic cyberpunk collage.
```

Use this structure for any board that must connect a hero environment, characters, a spatial diagram, and props in one visual language.

## Character roster grid

```text
Create one clean [2×5 or 3×3] character-roster board for an original game cast. Each equal card contains one different named adult character archetype with a distinct silhouette, face, hairstyle or head shape, costume, prop, expression, and accent color. Keep one shared rendering style, camera crop, figure scale, light direction, background treatment, card padding, border language, and world-specific material vocabulary across the full grid.
Assign every card's archetype and row-major position before generation. Use only short exact name labels when supplied. Preserve clear differences without drifting into unrelated worlds. No merged cells, duplicate characters, inconsistent age framing, random costume eras, illegible labels, franchise characters, or one card receiving substantially more detail than the others.
```

Possible content variants include a wholesome anime-fantasy party or a cyberpunk alien/android nightlife cast. Change the cast vocabulary, not the grid and consistency contract.

Evaluate silhouette diversity and role readability together with set-level cohesion. After selection, generate each accepted character under its own character-reference or production-asset contract.
